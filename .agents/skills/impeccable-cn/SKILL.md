# 界面精修

这是 Impeccable 的项目内中文适配版。它把设计工作拆成“审计 → 收敛 → 打磨 → 验证”，优先改善用户能感知的层级、密度、可读性和稳定性，而不是堆叠装饰。

## 工作流

1. **读取设计事实源**：先读仓库根 `AGENTS.md`、`docs/README.md` 和 UI 任务所需的 `DESIGN.md`；确认目标页面、受众、已有 token、组件和尺寸约束。
2. **做视觉审计**：检查信息层级、对齐、间距节奏、字体比例、颜色对比、边框/阴影、圆角一致性、响应式断点、焦点态和布局跳动。记录最影响体验的 3 个问题。
3. **给出设计读法**：用一句话说明页面气质与方向；若现有品牌和用户意图足够明确，不额外提问。
4. **收敛结构**：优先复用现有组件与 token。用数据驱动相似分支；删除重复标签、无意义状态和卡片套卡片。一个区域只保留一个清晰的视觉焦点。
5. **打磨实现**：使用稳定的 CSS/StyleX 属性，避免改变外部尺寸的 hover、loading 或 focus；补齐 hover、focus-visible、disabled、empty/error 和 reduced-motion 状态。
6. **浏览器验证**：启动对应 app，检查真实桌面和窄屏尺寸。重点确认文字不被裁切、卡片不横向溢出、操作目标可点击、状态切换不抖动。

## Tabora 约束

- 以 `DESIGN.md` 的 Refined Sage 为单一视觉基线：暖白页面、清晰边框、克制表面、紧凑排印；绿色强调色只用于主操作、选中态、焦点环和小型高亮。
- 复用 `@tabora/ui/*` 基础组件与现有宿主容器；插件内容不创建全局 modal、toast、fullscreen 或新的宿主壳体。
- 使用主题 CSS variables / StyleX tokens，不在组件里写死新的颜色；新图标优先 `lucide-solid`，不手写 SVG，不用 emoji 代替图标。
- 卡片默认用边框和空间表达层级，不使用重阴影；卡片圆角遵循现有 token，不引入 10px 以上的大圆角。
- Widget 内容组件负责自己的内部留白；宿主卡片壳不额外包标题头或 padding。S/M/L/XL 尺寸必须在实际网格中完整显示。
- 输入控件必须有可访问名称；交互元素有 pointer、hover、focus-visible；任何状态变化不得造成外部布局跳动。

## 反模板化检查

- 不默认使用 AI 紫色渐变、深色 mesh、玻璃拟态、随机发光或三列营销卡片。
- 不为了“设计感”增加无语义的标签、状态、装饰线或重复标题；每个元素都应服务于识别、层级或操作。
- 不混用多套圆角、字体或图标风格；先选择一个清晰的视觉签名，再贯穿所有尺寸和状态。
- 不用占位文案掩盖结构问题；标题尽量短，辅助文案控制在必要信息范围内。

## 交付前检查

- [ ] 设计方向与 `DESIGN.md`、用户明确偏好一致。
- [ ] 复用了现有组件、token 和图标体系；没有新增无真实消费者的抽象。
- [ ] 桌面、窄屏、hover、focus-visible、disabled 和 reduced-motion 均可用。
- [ ] 文本、图标和边框对比度可读；没有裁切、溢出或布局抖动。
- [ ] 运行受影响的 focused tests，再运行根回归摘要要求的检查；报告实际通过、失败和未覆盖项。
